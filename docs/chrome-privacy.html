HMK Kèthîra VTT Bridge for Chrome — Privacy

Last updated: November 5, 2026. The HMK Chrome Bridge connects locally opened HMK Kèthîra Workshop / DM Toolkit pages with a user-selected Roll20 game. Its purpose is to relay game rolls, supported character-owner messages, and related gameplay events, with optional local character backup downloads.

Information processed

It may process HMK character and player display names, game attributes and state relevant to supported events, roll results, messages between connected game participants, tab titles/addresses needed to identify authorized HMK and Roll20 tabs, bridge settings, and optional character backup snapshots.

Where information goes

Game messages and roll summaries selected for forwarding are sent to the user's selected Roll20 game, where Roll20 and the game's participants may receive them according to Roll20's services and the game's settings. The extension routes supported messages back to HMK tabs. Settings, limited history and optional backup snapshots are kept in Chrome's extension-local storage. Requested/automatic backup files are downloaded onto the user's computer. The extension does not send the game data to its developer or to a separate analytics service and does not sell the data.

Permissions and control

  • storage keeps bridge settings, connection state and optional backup records locally.
  • tabs detects and targets relevant HMK and Roll20 tabs.
  • downloads saves optional character backup files locally.
  • file:// access supports local HMK HTML tools, only when the user enables Allow access to file URLs in Chrome Extensions settings.
  • localhost / 127.0.0.1 supports HMK tools served from a local development server.
  • app.roll20.net supports the selected Roll20 game editor.

Control and third-party services

Users can turn off automatic event forwarding in the extension popup, disable the extension, or uninstall it to remove its local extension storage. Roll20's own privacy and access rules apply to data delivered to Roll20. The extension does not access the content of unrelated websites for analytics.

Changes

Any future release that materially changes these practices should update this policy and the Chrome Web Store disclosures before publication.
