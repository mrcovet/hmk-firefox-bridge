HMK Firefox Bridge — Data Handling

This extension relays game data from local HMK Workshop/DM Toolkit browser pages to other connected HMK pages and to the Roll20 game page the user has selected. Data may include fictional character attributes, game state, and character or player display names. The extension uses browser local storage for settings and optional local character backup. The bridge developers do not operate a telemetry/analytics server or receive these game data through this extension. Roll20 receives data intentionally posted to its game/chat service and is subject to its own terms. The extension does not send game data to the update website. The update website only hosts signed extension packages and a version manifest. Users can disable automatic VTT sending through the extension popup.
